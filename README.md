# Mini curso de Obsidian — Dominicode

Vaults de práctica para aprender Obsidian y conectar notas, conocimiento y Spec-Driven Development.

## Empieza aquí

1. Instala y configura Obsidian paso a paso.
2. Descarga este repositorio desde **Code → Download ZIP** y extrae su contenido, o clónalo con Git.
3. En Obsidian, elige **Abrir carpeta como bóveda / Open folder as vault** y selecciona `00-empieza-aqui`.
4. Abre **Home**: encontrarás la guía y una estructura de carpetas con notas de ejemplo para practicar dentro de la aplicación.

**Cada carpeta numerada se abre como un vault independiente.** Evita abrir todo el repositorio como una sola bóveda: los ejemplos repiten nombres de notas entre módulos.
